# Beyond the Classroom — Project Discovery

**Ace Pen Studio · Discovery Phase**

This repository contains the Project Discovery Questionnaire and related working materials for **Beyond the Classroom**, a project by Dr. Khadija Kishimba.

The questionnaire is designed to help Ace Pen Studio understand the wider vision for the project before developing recommendations, project architecture, and a detailed proposal.

## Purpose

The Discovery Phase is intended to clarify:

- The broader vision for *Beyond the Classroom*
- What Dr. Khadija Kishimba hopes to build around the book
- The audiences she wants to reach
- The ideas, themes and areas of expertise at the heart of the project
- Activities and initiatives already in motion
- The relationship between the book, Foundation work and other programmes
- Publishing and edition considerations
- Existing commitments, partners and timelines
- Where Ace Pen Studio may be able to contribute

The questionnaire is not intended to prescribe the project. It is a tool for understanding what already exists, what is emerging, and what the project could become.

## Workflow

The project currently follows a discovery-led process:

1. Project Discovery
2. Review of questionnaire responses
3. Project mapping and synthesis
4. Strategic recommendations
5. Project architecture
6. Proposal and workplan

The exact scope and structure of the subsequent work will be informed by the Discovery Phase.

## Notes

The questionnaire itself is designed to be completed through its hosted web page rather than through GitHub.
